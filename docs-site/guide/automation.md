# 依赖、模型与预算

## 计划依赖（DAG）

总管如果判断两件事有先后，会写：

```text
@老周 整理电源与热设计要点。
@小柯 写成《硬件开发流程.md》[依赖:@老周]
```

- 房间按**层**执行：同一层互不依赖的可以并行，下一层等上一层；
- 上游的文字结论会自动拼进下游任务上下文（`【上游 老周 的结论】…`）；
- 上游失败/被跳过，下游标 `blocked`，不会空跑；
- 依赖成环、指向未批准的任务，批准接口直接 400。

计划卡里每条任务都有一个「依赖」下拉：

- **沿用计划**：保留总管声明的依赖（可能多个）；
- **无依赖**：清空；
- **等待某件任务**：改成单个上游。

## 每 Bot 模型

Bot 库和房间成员编辑里都有「模型」下拉：

- 默认「跟随 DSH 默认」；
- 列表来自当前部署的 `llm` registry（`GET /models`）；
- 选中后，开跑前调用 DSH 的 `sessionController.selectModel({sessionId, provider, model})`，**下一次请求生效**；
- 同一个 Bot 续聊会继续用它自己的模型。

> 选模型时 DSH 会同时把这个选择记为默认模型（宿主行为）；新会话不指定模型时跟随它。

## 预算

编辑房间时可以设置三档预算（token）：

- **单轮**：一次 Run 的上限；
- **单人**：某只 Bot 在房间内的累计上限；
- **房间**：整个房间累计上限。

到线后下一轮直接拒跑并写系统消息；已经跑完的超支会留痕，拦不住。

设为 `0` 表示不限制。

## 决定谁接话

- `@名字`：只让被点名的 Bot 接；
- 只有一只 Bot：不 @ 也接；
- 多只 Bot + 有总管：总管接；
- 「仅 @ 响应」打开后，没 @ 到就不跑。

## 停止与超时

- 发送中的「停止」会 cancel 当前 Run；
- 单轮默认最多等 5 分钟，超时会明确标注「本轮被超时截断」；
- 配置：`%USERPROFILE%\.dsh\dshbot\config.json` 的 `runTimeoutMs`，或环境变量 `DSHBOT_RUN_TIMEOUT_MS`。
